# Pokemon API 🐾

**Experimental React + Vite app** built to practice frontend development with PokeAPI.

## Quick Overview
- Fetches Pokémon data from [PokeAPI](https://pokeapi.co)
- Search, list, and details UI for Pokémon
- Built with [React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB) + [Vite](https://img.shields.io/badge/Vite-%23646CFF?style=for-the-badge&logo=vite&logoColor=white)  
## Features
- Pokémon search & filtering
- Detailed Pokémon cards with sprites/stats
- Responsive design

## Run locally
```bash
git clone https://github.com/lucasciarinii/pokemon_api
cd pokemon_api
npm install
npm run dev
```
